# Contributing

For now, the only team authorized to contribute directly to this repository is [**websites-admin**](https://github.com/orgs/motchi-solutions/teams/websites-admin). Only members of that team may push branches or commits to the repository and merge changes.

Everyone else may create issues, fork the repository, and submit pull requests from their forks. Those pull requests require review and approval by `websites-admin`; opening a pull request does not grant direct repository access.

Read [the contributor guide](docs/CONTRIBUTING.md) for branches, pull requests, verification, content rules, and dependency changes. Start with [development setup](docs/DEVELOPMENT.md).
