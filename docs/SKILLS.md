# Agent skill inventory

This inventory covers the 12 installed skills under [`.agents/skills/`](../.agents/skills/). It excludes globally installed skills and connector tools. Motchi's approved content, brand, existing components, and [AGENTS.md](../AGENTS.md) take precedence over upstream defaults.

Source names for the original seven skills come from [skills-lock.json](../skills-lock.json); that file records content hashes, not upstream commit pins. The five newer pinned sources are recorded below. Sources identify provenance, not a claim that local files match the latest upstream. Read the actual installed `SKILL.md` and relevant helpers before use.

## Installed skills

## Modes and execution cautions

- **Security Audit:** Guidance uses only relevant material and does not create audit artifacts or start the six-phase workflow. Full audits are reserved for explicit full/comprehensive security reviews, pre-production/pre-launch reviews, major releases, major auth/backend/infrastructure changes, incidents, or significant trust-boundary changes. Upstream `quick`, `standard`, `deep`, and scoped runs are full-audit profiles, not the focused default. Keep certainty separate from severity and follow the repository's reporting/isolation rules.
- **Hallmark:** An audit is permission to review, not to redesign. Existing designs require the user to name Hallmark; upstream creation and `redesign` branches do not override approved Motchi content or task scope. `imagegen.mjs` sends a prompt and a bearer credential to `api.together.xyz`; `theme.mjs photos --save` downloads from `upload.wikimedia.org`. Browser helpers use Puppeteer/Chrome, can follow external assets, and may inspect environment-selected tool paths. Install/hook helpers can modify local or global agent locations/settings. None is implicitly authorized or advisory-cleared by installation.
- **Modern Web Guidance:** Run only `.agents/skills/modern-web-guidance/mwg search|list|retrieve` from the repository root. Search uses bundled embeddings/BM25 and `retrieve` reads bundled guides, verified with network denied by a macOS sandbox. `retrieve` output over 9.5 KB goes to a temporary `mwg-guide-*.md`; the CLI reads an optional `.mwgrc` (repository or home). Telemetry (installs, agent name, guide IDs, search queries) is sent only when `DISABLE_TELEMETRY` is unset, which the wrapper prevents; set it in your shell profile too if you ever run the CLI directly. The vendored `SKILL.md` is a marked local adaptation of upstream.
- **Unslop:** Default to polish mode and report larger ideas as suggestions. `snapshot.mjs <url|file> <out.html>` writes the HTML and a `.live.png` beside it; it launches Chrome without `--no-sandbox` but does not block external requests, so even a local file can load remote assets. `story.mjs` serves the story folder on `127.0.0.1` with path containment, writes and deletes `.story-frames/`, and runs `ffmpeg`. Both read only `CHROME_PATH` from the environment. Settings require a prompt before either runs; do not install ffmpeg or Playwright globally for it. Keep the CC BY 4.0 credit.
- **Untangle Codebase:** Use concrete coupling/ownership evidence and a bounded requested scope. Its broad upstream workflow is not authority for a rewrite, a persistent goal, or unrelated cleanup. Other instruction-only skills have no separate operating mode (`N/A`).
- **Local-only execution:** Security Audit's validators/tests still require the executable review policy even without direct network calls. Inspect only the relevant helper and dependencies; do not run a full audit to validate one tool call. Prefer local instructions when external access is unnecessary.

Preserve upstream notices, verify licenses before copying/executing third-party material, and perform the current advisory review required by `AGENTS.md` before any authorized external-call path.
